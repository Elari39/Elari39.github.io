## 这是什么

重庆锐强建筑劳务有限公司的官网：`/`、`/services`、`/gallery`、`/about`、`/contact` 五个页面，加上构建期生成的 `sitemap.xml` 与 `robots.txt`。纯静态、零后端，也没有 Route Handler——它要承担的不是业务，而是「把一家公司的可核实信息，清楚地摆出来」。

设计走的是 neobrutalism：粗黑描边、硬阴影、高饱和撞色。建筑劳务是个重体力的行当，界面不做玻璃拟态那套轻飘飘的东西，信息层级靠边框与留白拉出来。这与本站默认的那套主题是同一种语言。

## 三条纪律

**一、不编造任何企业事实。** 全站文案的每一个事实都必须能回溯到工商登记材料或项目原始素材。测试里有一张禁止词表（`承接过` / `已完成项目` / `众多客户` / `深耕多年` 之类），命中即删；这张表自身也有自检测试，确保每一条规则不是永远匹配不到的废规则。

**二、证件照永不发布。** 营业执照照含统一社会信用代码与法定代表人姓名。它不仅在 `public/` 下不存在，在构建管线的 `BLOCKED` 名单里被显式拒绝并 `exit 2`——即使有人把它塞进派生白名单，构建也会主动终止。需要展示的登记信息以**文字摘要**的形式呈现，而不是把证件照贴上去。

**三、元数据必须是绝对事实。** 这条来自一次真实事故：上线后 `canonical`、`og:url`、`og:image`、`sitemap.xml`、`robots.txt` 全部指向 `http://localhost:3000`，搜索引擎被指向一个不存在的域名、微信分享没有封面图，而页面看起来完全正常。当时的断言之所以没抓到，是因为它把产物与「同一进程里算出的 `SITE_URL`」比对——体检与病灶出自同一个值，于是恒真。现在域名以常量内置（`PRODUCTION_SITE_URL`），环境变量只作可选覆盖，且覆盖值不是干净的 https 主机名时**直接终止构建**。

## 图片与字体

`public/images/` 下的派生品不是手工放进去的，而是由脚本从 `img/` 生成的白名单产物：`BLOCKED` 优先于白名单，webp 与 avif 各 1600 / 800 两档、单图 < 300 KB，重复运行结果一致。仓库里不含营业执照照与工商登记摘要源文件——在一台全新克隆的机器上直接跑图片命令会因缺源图而终止，那是合规闸门在按设计工作，不是坏了。

字体是另一种「不外包」：拉丁字形用 Archivo Black（标题）与 Space Grotesk（正文），汉字用 Noto Sans SC 的 400 / 500 / 900，全部由 `next/font` 在构建期自托管到本站，不外链任何字体 CDN；再靠 `unicode-range` 子集化把每个字重切成上百个分片，浏览器只下载页面实际用到的那几片。字体未就绪时由 `display: "swap"` 加一列 CJK 兜底链先顶上，不会出现隐形文字。

## 技术栈

| 层 | 选型 | 为什么 |
| --- | --- | --- |
| 框架 | Next.js 16.3.6 + React 19.3（App Router） | 页面在构建期静态生成，`next.config.ts` 里没有 `output: "export"`，源码层不绑定任何平台 |
| 样式 | Tailwind CSS 4 | 圆角、阴影这些形状值在产物 CSS 里被断言，防的是「改了变量、忘了形状」 |
| 测试 | Vitest 5（当前测试清单见项目仓库） | 分源码层、元数据层、环境契约层、产物层，产物层读 `.next/` 而不是重新编译的源码 |
| 探针 | 自写 headless Chrome + CDP 脚本 | 三档响应式与灯箱 / 汉堡菜单 / 悬浮条这些交互，只有真点一遍才算验收 |
| 部署 | Netlify（Git 集成） | 仓库里唯一与平台相关的文件是 `netlify.toml`；换平台只需增删这一个文件 |

## 如实划界

- **地图不含精确坐标。** 注册地址的经纬度在现有材料里没有出处，所以刻意留空，走「把完整地址交给图商做关键词检索」的路线——一个标错的地图点比没有标点更糟。
- **ICP 备案号未展示。** 境外托管无需备案，当前也无备案信息，故不渲染空模块。
- **没有客户评价、项目业绩、资质荣誉模块。** 材料里没有这些事实，按纪律不建模块、不编造。
- **图版里的窗口外框是合成的。** CDP 只能截到页面内容，拿不到浏览器自身的标签栏与地址栏，外框由该项目脚本按其设计令牌用 HTML 渲染合成；图右下角那个 `Powered by Netlify` 角标则是免费套餐真实注入的，没有修图抹掉。
