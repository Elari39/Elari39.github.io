**重庆Golang就业市场适配规划（2026年3月-6月，保障6月前拿到实习）**

重庆Golang岗位主要集中在后端开发（互联网、金融科技、AI/智能制造、本地SaaS），2026年3月BOSS直聘/猎聘数据显示：  
- 实习/初级岗薪资100-200元/天（云从科技等AI公司有Golang后端实习），正式8-20K（中级15K+常见）。  
- **核心要求**：Go并发（goroutine/channel）、Gin框架、GORM、MySQL+Redis缓存、高并发API、Docker部署；加分项：消息队列（RabbitMQ/Kafka）、分布式（一致性哈希/微服务）、WebSocket实时通信、AI后端集成。  
- **你的优势**：ML/DL背景 + 二本但项目驱动 + 日本语CJT-6（少数岗位可能涉日企合作）。云从科技（Cloudwalk）等AI公司特别匹配你的GopherAI项目。  

**总体策略**（3个月紧凑计划，每天5-8小时）：  
- **先基础后项目**：用你的学习资源（极客时间入门课 + TonyBai进阶课），边学边做项目。  
- **项目顺序**：由易到难，全部从零到完整部署到GitHub（带README、Dockerfile、测试、部署截图），简历突出“独立完成XX分布式/AI系统”。  
- **LeetCode**：用**代码随想录**（Go版优先）或halfrost书，专注后端高频题（数组/链表/树/哈希/并发相关），总刷150题左右（够重庆初级面试）。  
- **每周复盘**：GitHub commit + 写1篇Notion笔记（“我怎么解决缓存击穿/流式输出”），5月底前准备简历+作品集。  
- **求职节点**：5月中投递云从科技、猪八戒网、本地SaaS/区块链公司；6月前至少2-3个实习offer概率极高（项目匹配度>90%）。  

### **阶段1：Go基础 + 入门Web项目（2026.3.1-3.20，3周）**
**目标**：打牢语法+并发，完成第一个可运行项目，简历有“Go Web服务”条目。  

**学习任务**：  
- 完成《极客时间 Go语言入门到实战》全课程（语法、并发、包管理、测试、error处理）。  
- TonyBai进阶课前10讲（模块/接口/并发进阶）。  
- Linux基础 + Git + Docker入门（安装+简单镜像）。  

**项目**：  
- **短链接系统**（TonyBai《Go语言进阶课》实战项目）。  
  从零实现：短码生成（Base62/雪花ID）、Redis布隆过滤器防穿透、MySQL持久化、Gin REST API、302跳转、高并发计数。  
  部署：Docker + 本地/免费云服务器跑通。  

**LeetCode**（40-50题，代码随想录前4章）：  
- 数组、链表、字符串、栈/队列。用Go写，重点练双指针、哈希表、模拟。每天8-10题。  

**里程碑**：项目GitHub星标自测通过，写README（架构图+性能测试）。  

### **阶段2：Web框架 + 缓存系统（3.21-4.15，4周）**
**目标**：掌握生产级后端，缓存项目直接对标大部分重庆初级岗要求。  

**学习任务**：  
- Gin全家桶（路由、中间件、参数校验、JWT认证）。  
- GORM + MySQL（CRUD、事务、索引）。  
- Redis（String/Hash/List/Set、缓存一致性、过期/淘汰）。  
- TonyBai进阶课中间部分（设计模式、性能调优）。  

**项目**：  
- **KamaCache-Go**（完整从零实现）。  
  实现LRU淘汰、一致性哈希分片、singleflight防雪崩、分布式节点（etcd服务发现可选）、客户端/服务端RPC。  
  扩展：加Gin监控接口，Docker多节点部署测试。  
  （此项目完美覆盖“缓存系统”高频面试题）  

**LeetCode**（50题，代码随想录5-8章）：  
- 哈希表、树（二叉树/BST）、回溯。重点Go并发题（如交替打印）。  

**里程碑**：缓存系统支持1000QPS压测，GitHub有benchmark截图。  

### **阶段3：分布式 + AI集成（4.16-5.15，4周）**
**目标**：做出高含金量项目，直接对标云从科技等重庆AI/分布式岗位，成为简历核心竞争力。  

**学习任务**：  
- WebSocket + Kafka/RabbitMQ（消息队列、实时推送）。  
- 分布式系统（微服务、负载、CAP）。  
- Docker Compose + Kubernetes基础（单机部署多服务）。  
- TonyBai进阶课后半部分 + EINO框架文档（字节AI）。  
- 你的ML知识复用：ONNX模型推理。  

**项目**（并行推进，优先GopherAI）：  
- **GopherAI（eino+gin）**（核心项目，强烈推荐先做）。  
  完整实现：Gin API + EINO多模型流式对话、SSE实时输出、多会话上下文、RabbitMQ异步、MySQL用户/会话、Redis缓存、ONNX图像识别（MobileNetV2）、工厂模式扩展模型、Vue前端对接、Docker全栈部署。  
  （你的ML背景直接加分，云从科技等AI公司看到会眼前一亮）  

- **KamaChat（分布式聊天室+仿微信）**（5月上旬）。  
  WebSocket实时单/群聊、Kafka消息转发、文件/视频上传、联系人/群管理、音视频通话信令、后台管理。  
  Docker Compose多节点部署（模拟分布式）。  

**LeetCode**（40-50题，代码随想录9-12章 + 剑指Offer Go版）：  
- 图、动态规划、堆、滑动窗口、并发经典题。总刷量达150题，刷题记录截图放简历。  

**里程碑**：两个大项目均上线（可免费部署到Render/ Railway），写2篇技术博客（知乎/掘金/CSDN）：“Go实现AI流式聊天服务”“从零搭建分布式IM系统”。
